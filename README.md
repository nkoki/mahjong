# 麻雀点数計算アプリ（4人打ち）

4人打ちリーチ麻雀の **点数計算・対局管理・戦績記録** を行う Flutter アプリです。

- フレームワーク: Flutter 3.22 以上 / Dart 3.4 以上
- 状態管理: Riverpod（`flutter_riverpod`）
- 対応: Android / iOS（確認用に Web も同梱）

## 実行方法

Flutter SDK のインストールと PATH の設定が必要です（`flutter --version` で確認できます）。
PowerShell でも動くように、1行ずつ実行してください。

```bash
git clone https://github.com/nkoki/mahjong.git
cd mahjong
flutter pub get
flutter run -d chrome   # Chrome で起動（スマホのエミュレータ・実機なら flutter run）
flutter test            # アプリのテスト（対局進行・保存・画面操作）
cd packages/mahjong_score_engine
dart test               # 点数計算エンジンのテスト
```

## Web 版の公開（GitHub Pages）

`main` に push すると、GitHub Actions（GitHub が自動で処理を実行する仕組み）が `.github/workflows/deploy-pages.yml` に沿って、
テスト → Web 版のビルド → GitHub Pages への公開を行います。公開先は `https://nkoki.github.io/mahjong/` です。

- 初回だけ、GitHub のリポジトリの **Settings → Pages → Build and deployment → Source** を **GitHub Actions** にしてください。
- 非公開（Private）のリポジトリで GitHub Pages を使うには、有料プラン（GitHub Pro など）が必要です。
- テストが失敗した場合は公開しません（前回公開したものがそのまま残ります）。
- iPhone で使うときは、Safari で開いて共有ボタンから「ホーム画面に追加」すると、アプリのように起動できます。
  ホーム画面から使わないと、7日間開かなかったときに Safari が保存データを消すことがあります。

## 機能

| 機能 | 内容 |
|---|---|
| 新規対局 | 4人の名前、半荘戦／東風戦、持ち点（配給原点）、返し、ウマ、トビの有無。持ち点・返し・ウマは、よく使う値のボタンのほかに、テキストボックスで自由な値も入力できる（持ち点・返しは100点単位、ウマは1位〜4位を千点単位で、合計0） |
| ダッシュボード | 現在の局・本場・供託、4人の点数・自風・順位・トップとの差、立直の宣言／取消、1つ前に戻す |
| 和了入力 | 和了者・ロン／ツモ・放銃者、手牌（牌パレットで入力）、和了牌、鳴き（チー・ポン・明槓・加槓・暗槓、赤5指定可）、ドラ表示牌・裏ドラ表示牌、状況役（立直・ダブル立直・一発・嶺上開花・槍槓・海底・河底・天和・地和） |
| ダブロン | ロンの計算結果画面から「ダブロン：もう1人のロン和了を入力」で2人目を入力し、2人分をまとめて確定できる（放銃者・和了牌・ドラ表示牌は1人目と同じものが入る）。トリロン（3人）は流局の「三家和」として扱う |
| 計算結果 | 役一覧と翻数、符の内訳、満貫などの名称、点数（例: 1300-2600 / 4000オール）、全員の点数移動（本場・供託込み） |
| 流局入力 | 荒牌平局（ノーテン罰符）、流し満貫、九種九牌、四風連打、四家立直、四開槓、三家和 |
| 戦績 | 対局一覧、最終順位とポイント（ウマ・オカ込み）、局ごとの点数増減表と内容。★でお気に入り登録・お気に入りだけの絞り込み。戦績詳細ではウマだけ後から変更でき、ポイントがすぐに計算し直される |
| 局の修正 | 戦績詳細で過去の局をタップすると、その局の点数の増減と内容のメモを修正できる。差分はその局以降の点数と今の点数に反映（4人の合計は修正前と同じにする。局の進行・終局は変わらない。終局時の供託は修正後のトップに付け替え）。修正済みの局には印が付き、保存直後の「元に戻す」で取り消せる |
| データ保存 | 対局データを端末に自動保存（アプリを閉じても残り、「続きから」再開できる。「元に戻す」も直近10回分まで保存） |
| バックアップ | 全対局を1つのファイル（JSON）に書き出して保存し、あとで読み込める（機種変更・データ消失への備え）。ファイルを扱いにくいときはテキストでコピー・貼り付けもできる。読み込み時は「今のデータに追加」か「すべて置き換え」を選ぶ。最後にバックアップした日時をホーム画面に表示し、未実施・30日以上前なら注意を表示 |
| 保存のお知らせ | ホーム画面に保存状況（対局数・容量、Web 版は上限に対する使用率）を表示。「データの保存について」画面で注意点を説明。保存の失敗・壊れたデータ・容量の上限が近いときは画面でお知らせ |
| カメラ認識 | 設計のみ（`lib/features/camera/tile_recognizer.dart`。Qwen API 用の指示文と応答解析を用意、通信部分は未実装） |

## 採用しているルール

- 喰いタンあり、赤ドラあり（各色の5に1枚ずつ）
- 切り上げ満貫なし（4翻30符 = 7700点 / 親11600点）
- 数え役満あり（13翻以上）
- ダブル役満あり: 四暗刻単騎、国士無双十三面待ち、純正九蓮宝燈、大四喜。役満の複合あり
- 連風牌（場風かつ自風）の雀頭は4符
- 本場: ロン300点 / ツモ各100点、供託リーチ棒は和了者が獲得（流局時は持ち越し、終局時はトップが獲得）
- 親の和了・親テンパイの流局・途中流局は連荘（本場+1）。子の和了は親流れで本場0に
- ダブロンあり: 放銃者が2人分の点数を払う。本場・供託は、放銃者から見て打つ順番が近い和了者が受け取る（上家取り）。和了者に親がいれば連荘
- トリロンは流局（三家和）
- 終局: 最終局が終わったとき、トビ（0点未満、設定時）、オーラスで親が和了してトップのとき（和了止め）、またはメニューから手動で終了
- 同点の順位は起家に近い人が上位
- 複数の解釈ができる手（例: 二盃口と七対子、三暗刻と一盃口、両面と嵌張）は最も点数が高いものを採用（高点法）

## データの保存について

- 保存には `shared_preferences` を使っています。保存場所は Android では SharedPreferences、iOS では NSUserDefaults、Web ではブラウザの localStorage です。
- 対局ごとに別のキー（`mahjong_session_<対局ID>`）に JSON（テキスト形式のデータ）で保存し、対局の並び順は目次（`mahjong_session_index`）に保存します。
- 対局の状態が変わるたび（立直・和了・流局・元に戻す・削除など）に、**変わった対局だけ**を自動で保存します。何百対局あっても、1回の保存は対局1つ分（約5KB・1ミリ秒未満）で済みます。
- 「元に戻す」の履歴（直近10回分）には、局ごとに変わる値（点数・局・本場など）と「局の記録は何局目まで」という件数だけを保存し、局の記録の文章は1回だけ保存します。
- 容量の目安: 1対局（半荘・12局程度）で約5KB、100対局で約0.5MB です。Web の localStorage の上限（約5MB、ブラウザによって違う）に近づくのは800〜1,000対局くらいからです。
- 保存データにバージョン番号を付けているので、将来データの形を変えるときに移行できます（現在は version 3。全対局を1つにまとめて保存していた以前の version 1・2 のデータは、起動時に自動で新しい形に移します）。
- 保存データが壊れていて読み込めない場合も、アプリは落ちずに起動します。壊れているのが一部の対局だけなら、その対局以外はそのまま読み込みます。壊れたデータは消さずに `mahjong_corrupt_` で始まる別の名前で残します。目次が壊れた場合は、対局データから作り直します。
- アプリをアンインストールしたり、ブラウザのサイトデータを消したりすると、保存データも消えます。備えとして、バックアップ画面から全対局をファイルに書き出せます。
- 保存するのは**最新100対局まで**です。100件を超えると、新しい対局を始めたときに、**お気に入り（★）にしていない一番古い終局済みの対局**から自動で削除します。削除する前に、どの対局が消えるかを確認画面で表示します。
  - お気に入りの対局と対局中の対局は削除しません。それらだけで100件を超えた場合は、100件を超えて保存します。
  - 戦績一覧には「保存中: ○ / 100件」と、次に削除される対局の印を表示します。
- Web 版はブラウザの容量の上限（約5MB）があるので、その50%を超えるとホーム画面で警告します。
- 保存に失敗したとき（容量不足など）はどの画面でもお知らせし、ホーム画面にも表示し続けます。読み込めなかったデータがあったときもホーム画面でお知らせします。

## 点数計算エンジンの使い方

```dart
import 'package:mahjong_score_engine/mahjong_score_engine.dart';

final result = ScoreCalculator.calculate(
  const WinInput(
    handTiles: ['2m','3m','4m','5mr','6m','7p','8p','9p','2s','3s','4s','5s','5s'],
    winningTile: '1m',
    melds: [],
    winType: 'tsumo',
    isRiichi: true,
    isIppatsu: false,
    isDoubleRiichi: false,
    doraTiles: ['4m'],
    uraDoraTiles: [],
    roundWind: '1z',  // 場風: 東
    playerWind: '2z', // 自風: 南（子）
  ),
  honba: 0,
  riichiSticks: 1,
);
print(result); // 役・翻・符・点数
```

牌の表記: `1m`〜`9m`（萬子）、`1p`〜`9p`（筒子）、`1s`〜`9s`（索子）、`1z`〜`7z`（東南西北白發中）、赤5は `5mr` `5pr` `5sr`。

ツモ和了の `PaymentDetail.playerPayments` の `playerId` は **支払う人の自風**（0=東家(親), 1=南家, 2=西家, 3=北家）です。
